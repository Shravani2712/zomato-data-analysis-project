## 🎯 Business Problem & Objective

The goal of this project is to analyze Zomato restaurant data to help understand:

- 🍽 Popular cuisines and restaurant categories  
- ⭐ Customer ratings and voting patterns  
- 💰 Pricing trends across cities and locations  
- 🚚 Online delivery vs dine-in performance  
- 📍 Location-wise restaurant distribution  
- 📊 Business insights for decision-making in the food-tech industry

## 🔍 Data Analysis Workflow

1. **Data Collection**
   - Imported Zomato restaurant datasets from CSV & Excel sources  

2. **Data Cleaning & Preprocessing**
   - Removed duplicates  
   - Handled missing values  
   - Standardized columns and formats  

3. **Exploratory Data Analysis (EDA)**
   - Analyzed ratings, cuisines, votes, and pricing trends  
   - Identified patterns and outliers  

4. **SQL Analysis**
   - Used joins, group by, filters, and aggregations  
   - Generated business-focused insights  

5. **Visualization & Dashboards**
   - Built dashboards using Excel, Tableau, Power BI  
   - Developed an interactive **Streamlit web dashboard**

6. **Insights & Reporting**
   - Converted data findings into actionable insights  

---

## 📈 Key Insights & Findings

- ⭐ Identified **top-rated restaurants and cuisines**
- 🍜 Popular cuisines vary significantly by city
- 💰 Higher price range does not always guarantee higher ratings
- 🏙 Certain cities dominate restaurant density and customer engagement
- 🚚 Online delivery availability impacts customer voting behavior
- 📍 Location data reveals clustering of high-rated restaurants
